# BreakEight

Eight-bar breakdown desk for bedroom producers stuck in 8-bar loops.

Live FluidR3 chairs strip density and create space so the main section has a place to go. Distinct from RiseFour (intensity build), TwistEight (harmonic twists), ContrastFour (four-bar), CloseFour (closing).

## Features
- BPM 60–180, key selector, bar count
- Audio-clock lookahead scheduler (no timer drift)
- Live changes apply on next step
- Sparse pad, piano, bass, kick using pinned FluidR3 samples
- localStorage persistence
- WAV 48 kHz / 24-bit + MIDI exports (grid-perfect, seamless loop)
- Mobile-friendly, tap-to-start, visibility stop
